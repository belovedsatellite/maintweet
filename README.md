# 소개표 메이커

트위터(X) 메인트윗에 올릴 **자기소개표 이미지**를 브라우저에서 바로 만들어 PNG/JPG로 저장하는 도구예요.
회원가입이나 설치 없이 쓸 수 있고, 올린 이미지는 어디에도 전송되지 않고 내 브라우저 안에서만 처리돼요.

## 이런 걸 만들 수 있어요

- 왼쪽에 계정 정보, 오른쪽에 좋아하는 캐릭터·페어 이미지를 두는 **가로형 소개표** (세로형도 가능)
- 프로필 사진·헤더, 닉네임·아이디
- **ACCOUNT / GENRE / DREAM** 성향 키워드 (기본 키워드를 켜고 끄거나 직접 추가)
- **ABOUT / CAUTION / NG** 자유 입력란
- 이미지마다 장르명, 캐릭터·페어명, 출처 캡션과 액자
- 스티커와 텍스트(말풍선, 인용구, 메모지, 테이프 등) 꾸미기

### 테마 8종

| 테마 | 분위기 |
|---|---|
| 심플 | 여백과 가는 선의 깔끔한 기본형 |
| 다이어리 | 줄 노트, 폴라로이드, 마스킹테이프 |
| 시네마 | 레터박스, 엔딩 크레딧, 필름 스트립 |
| 디텍티브 보드 | 코르크 보드, 핀, 이미지를 잇는 붉은 실 |
| 매거진 | 큰 제목과 굵은 선의 에디토리얼 |
| SNS 화면 | 앱 상단바, 게시물 카드, 해시태그 |
| 미술관 | 전시 벽면과 조명, 작품 명판 |
| 우주 | 별이 찍힌 우주, 인공위성과 우주비행사 |

테마마다 색 조합이 여러 개 있고, 색 9가지를 컬러피커로 직접 바꿀 수도 있어요.

## 사용법

1. **프로필** 탭에서 프로필 사진, 헤더, 닉네임, 아이디를 넣어요.
2. **성향** 탭에서 키워드를 눌러 켜요. 켜진 키워드만 소개표에 들어가요. 쉼표로 여러 개를 한 번에 추가할 수 있어요.
3. **소개** 탭에서 ABOUT, CAUTION, NG를 적어요. 비워 둔 칸은 자동으로 빠져요.
4. **이미지** 탭에서 좋아하는 캐릭터·페어 이미지를 여러 장 올리고, 한 줄에 몇 개씩 놓을지 정해요. 이미지마다 캡션과 액자를 고를 수 있어요.
5. **꾸미기** 탭에서 스티커나 텍스트를 올려요.
6. **테마** 탭에서 테마·색 조합·글꼴·배치·크기를 고르고, 오른쪽 위 **이미지 저장**을 눌러요.

### 알아 두면 편한 것

- 미리보기에서 **고치고 싶은 부분을 누르면** 해당 편집 칸으로 바로 이동해요.
- 미리보기의 이미지, 프로필 사진, 헤더는 **끌어서 위치를 옮기고, 마우스 휠로 확대**할 수 있어요.
- 이미지 목록과 꾸미기 목록은 왼쪽 **⠿ 손잡이를 끌어서 순서를 바꿔요.** 손잡이를 선택하고 ↑↓ 방향키로도 옮길 수 있어요. 꾸미기 목록은 위쪽일수록 앞에 보여요.
- 스티커·텍스트는 끌어서 옮기고, 파란 점을 끌어 크기를 바꿔요. 선택한 상태에서 방향키로 1px(Shift는 10px)씩 옮기고 Delete로 지워요.
- 슬라이더 옆 숫자 칸에 값을 직접 입력할 수 있어요. 회색 글씨가 입력 가능한 범위예요.
- 텍스트 꾸미기는 **꾸밈 높이 직접 정하기**를 켜면 글자 양과 상관없이 높이를 정하고, 글자를 위·가운데·아래로 정렬할 수 있어요.
- **Ctrl+Z / Ctrl+Shift+Z** (Mac은 ⌘)로 되돌리기·다시 실행할 수 있어요. 글자를 입력하는 칸 안에서는 그 칸의 글자만 되돌려져요.
- 오른쪽 위 배율 메뉴에서 미리보기를 **실제 크기(100%)** 로 바꿔 세부를 확인할 수 있어요.
- 저장 버튼 아래 작은 숫자가 저장될 이미지의 실제 크기예요. 트위터에는 기본 해상도로도 충분하고, 고화질은 확대해 봤을 때 더 선명해요.

## 작업 저장과 백업

- 작업 내용은 **지금 쓰는 브라우저에 자동 저장**돼요. 다른 기기나 다른 브라우저에서는 보이지 않아요.
- 브라우저 저장 공간은 크지 않아서, 이미지를 많이 넣으면 자동 저장이 안 될 수 있어요. 이때 왼쪽 위에 빨간 표시가 떠요.
- 오래 보관하거나 다른 기기에서 이어 하려면 **저장** 탭의 **프로젝트 파일 저장(.json)** 으로 백업해 두세요. 같은 탭에서 다시 불러올 수 있어요.
- 브라우저 기록·사이트 데이터를 지우면 자동 저장된 작업도 함께 지워져요.

## 자주 묻는 것

**저장한 이미지의 글꼴이 미리보기와 달라요.**
글꼴은 Google Fonts에서 불러와요. 인터넷이 불안정하거나 광고 차단 확장 프로그램이 글꼴을 막으면 기본 글꼴로 저장될 수 있어요. 새로고침 후 다시 저장해 보세요.

**아이폰 사파리에서 저장이 안 돼요.**
저장 버튼을 누른 뒤 뜨는 다운로드 안내를 확인하고, '파일' 앱의 다운로드 폴더를 열어 보세요.

**올린 이미지가 서버에 남나요?**
아니요. 이 사이트에는 서버가 없고, 모든 처리는 내 브라우저 안에서 이뤄져요.

## 개인정보

- 올린 이미지와 입력한 글은 외부로 전송되지 않아요.
- 글꼴을 불러오기 위해 Google Fonts(fonts.googleapis.com, fonts.gstatic.com)에, 이미지 변환 라이브러리를 불러오기 위해 jsDelivr(cdn.jsdelivr.net)에 접속해요. 이 과정에서 접속 IP 등 일반적인 접속 정보가 해당 서비스에 전달될 수 있어요.
- 방문 통계나 광고 추적 도구는 쓰지 않아요.

## 이미지 사용 시 유의할 점

다른 사람이 그린 그림이나 커미션 이미지를 쓸 때는 작가가 정한 이용 범위를 지키고, 출처 칸에 표기해 주세요.

## 사용한 오픈소스

- [html-to-image](https://github.com/bubkoo/html-to-image) 1.11.11 — MIT License. 소개표를 이미지로 변환하는 데 써요.
- [Google Fonts](https://fonts.google.com)의 글꼴들 — 각 글꼴의 라이선스(SIL Open Font License 1.1 또는 Apache License 2.0)를 따르며, 만든 이미지에 자유롭게 쓸 수 있어요.
  - 본고딕(Noto Sans KR), IBM Plex Sans KR, 고운돋움, 고운바탕, 나눔명조, 함렛, 개구, 나눔손글씨 펜, 도현, 주아, 검은고딕, Outfit, Bebas Neue, Oswald, Cinzel, Playfair Display, DM Serif Display, Special Elite, Courier Prime, Space Grotesk

## 직접 배포하기

정적 파일(`index.html`, `style.css`, `app.js`)만으로 동작해요. GitHub Pages라면 저장소 루트에 파일을 올리고 **Settings → Pages**에서 Branch를 `main` / `/(root)`로 지정하면 돼요.
