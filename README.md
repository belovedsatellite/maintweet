# 트위터 소개표 메이커

트위터(X) 메인트윗에 올릴 소개표 이미지를 브라우저에서 만들고 PNG/JPG로 저장하는 정적 웹사이트입니다. 서버 없이 GitHub Pages에 그대로 올려 쓸 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (편집 패널 + 미리보기) |
| `style.css` | 편집기 UI와 소개표 카드 스타일 |
| `app.js` | 편집 기능, 테마, 스티커, 이미지 내보내기 |

## 기능

- **레이아웃**: 왼쪽 정보 · 오른쪽 이미지(기본), 좌우 반전, 세로형. 정보 영역 너비(28~62%), 이미지 영역 세로 정렬
- **크기**: 가로 1200 / 1600 / 1920px, 기본 비율 2:1 · 16:9 · 3:2 · 4:3 · 1:1 · 4:5 · 3:4. 내용이 길면 세로가 자동으로 늘어남
- **테마 9종** (테마마다 색 조합 3~5개 + 색 9가지 직접 지정)
  - 심플: 여백과 가는 선의 깔끔한 기본형
  - 다이어리: 줄 노트, 링 구멍, 폴라로이드, 마스킹테이프, 형광펜 제목
  - 시네마: 레터박스, 엔딩 크레딧식 정보, 필름 스트립 이미지
  - 스테이지: 벨벳 커튼과 조명, 금테 액자, 무대 바닥
  - 디텍티브 보드: 코르크 보드, 핀으로 꽂은 메모, 이미지를 잇는 붉은 실
  - 매거진: 큰 제목과 굵은 선의 에디토리얼
  - SNS 화면: 앱 상단바, 팔로우 버튼, 게시물 카드, 해시태그, 미디어 그리드
  - 미술관: 전시 벽면과 조명, 하단 징두리 벽, 작품 명판 캡션
  - 우주: 별이 찍힌 검은 우주, 행성 가장자리, 인공위성·우주선·우주비행사(끄기 가능)
- **액자**: 이미지별로 금색 클래식·은색·원목·블랙/화이트 매트·원형·타원 액자 선택, 기본 액자 일괄 지정 (모든 테마에서 사용 가능)
- **프로필**: 프로필 사진(원형·둥근 사각·사각, 크기 조절), 헤더 이미지(선택), 닉네임, 아이디
- **성향**: ACCOUNT · GENRE · DREAM 키워드 켜기/끄기, 직접 추가(쉼표로 여러 개), 삭제, 제목 변경, 배치 3종
- **소개**: ABOUT · CAUTION · NG (비우면 자동으로 빠짐)
- **이미지**: 개수 제한 없음, 한 줄 개수(1~6) 지정 시 자동 정렬, 장르명·캐릭터/페어명·출처 캡션, 비율, 세로 위치, 순서
- **꾸미기**: 스티커 이미지 + 텍스트 6종(텍스트, 말풍선, 외곽선 말풍선, 인용구, 메모지, 테이프). 끌어서 이동, 핸들로 크기·너비 조절, 회전·투명도·글꼴·정렬·굵게·색 지정, 말풍선 꼬리 위치, 복제, 앞뒤 순서
- **저장**: 브라우저 자동 저장, 프로젝트 파일(.json) 저장·불러오기, PNG/JPG(기본 / 2배 해상도). 이전 버전에서 만든 내용도 불러와짐

## 참고

- 업로드한 이미지는 서버로 전송되지 않고 사용자의 브라우저 안에서만 처리됩니다.
- 자동 저장은 브라우저 저장 공간(약 5MB)을 씁니다. 이미지가 많으면 용량을 넘을 수 있으니 **저장 탭 → 프로젝트 파일 저장**으로 백업해 두세요.
- 아주 긴 소개표를 고화질로 저장하면 브라우저 한도에 맞춰 해상도가 자동으로 조금 낮아집니다.
- 외부 라이브러리: [html-to-image](https://github.com/bubkoo/html-to-image) (jsDelivr CDN), 글꼴은 Google Fonts를 사용합니다.
